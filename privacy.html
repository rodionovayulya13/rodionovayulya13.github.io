Приложение «reels» · редакция от 11 сентября 2026

«reels» — личный инструмент автора для публикации собственных видеороликов на YouTube и в TikTok. Приложение не является публичным сервисом.

Какие данные используются

Приложение обращается к YouTube Data API и TikTok Content Posting API только от имени владельца аккаунтов и только для загрузки его собственных видео. Используются токены доступа, выданные после явного подтверждения владельцем. Данные других пользователей не запрашиваются, не хранятся и не передаются.

Где хранятся данные

Токены доступа хранятся локально, на личном компьютере владельца. Серверов, баз данных на стороне и сторонних получателей нет. Видео отправляются напрямую на YouTube и в TikTok.

Передача третьим лицам

Данные не передаются третьим лицам, не продаются и не используются для рекламы или аналитики.

Отзыв доступа

Доступ можно отозвать в любой момент: для Google — на странице myaccount.google.com/permissions, для TikTok — в настройках аккаунта в разделе управления приложениями.
